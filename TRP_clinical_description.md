# Совокупный репродуктивный потенциал (TRP)
## Методологическое описание для клинического персонала

---

### Какой вопрос решает TRP

Основной модуль Digital Twin отвечает на вопрос текущего цикла: какова вероятность
наступления беременности *при данных параметрах стимуляции, данном эмбриологическом
ответе и данном числе попыток*? Это точечный прогноз, опирающийся на полный набор
лабораторных данных — ооциты, MII, 2PN, бластоцисты — и нейросетевую ансамблевую
модель (KAT).

TRP отвечает на другой вопрос: **каков репродуктивный ресурс пары на временно́м
горизонте?** Сколько биологически осуществимых попыток остаётся до закрытия
окна возможностей? Как суммарная вероятность беременности нарастает от цикла к
циклу? Когда снижение овариального резерва или возрастной фактор начнут ощутимо
менять прогноз? Это стратегический инструмент для консультирования — не замена
основному прогнозу, а его продолжение во времени.

---

### Архитектура расчёта: два слоя

#### Слой 1 — Якорь KAT (текущий цикл)

Вероятность для первого будущего цикла берётся непосредственно из основного
pipeline: значение `p_overall_cycle` — это совокупная вероятность беременности
за текущий цикл, включающая риск отмены (пустого цикла), вероятность получить
жизнеспособный эмбрион и вероятность наступления беременности при переносе.
Это число откалибровано нейросетевым ансамблем KAT, поправкой NVSA и
байесовским клиническим prior — оно правильное в абсолютном смысле.

#### Слой 2 — Аналитическая экстраполяция (будущие циклы)

Для каждого последующего цикла вероятность вычисляется по формуле:

```
logit(p_s) = logit(p_base)
           + [logit_FORTUNE(возраст_s, АМГ_s) − logit_FORTUNE(возраст_0, АМГ_0)]
           − 0.08 × s
```

Три компонента имеют самостоятельный клинический смысл:

`logit(p_base)` — откалиброванная стартовая точка из KAT. Не популяционная
медиана, а персонализированная оценка для конкретной пациентки.

`Δlogit_FORTUNE` — относительное изменение прогноза по мере старения и
снижения АМГ. Модель FORTUNE (Calhaz-Jorge et al., Hum Reprod 2015) используется
здесь исключительно как мера *направления* изменений, но не как источник
абсолютных значений. Благодаря этому биологический drift корректно учитывается
без искажения исходного калиброванного уровня.

`0.08 × s` — эффект отбора попыток (Malizia et al., NEJM 2009). Пациентки,
которые продолжают лечение после неудачных циклов, в совокупности представляют
менее благоприятную прогностическую группу, чем стартовая популяция. Коэффициент
0.08 на логит-шкале соответствует примерно 7–9% относительного снижения
вероятности за каждую дополнительную попытку — это популяционная оценка,
воспроизведённая в нескольких независимых когортах.

#### Моделирование снижения АМГ

Для построения траекторий будущих циклов АМГ экстраполируется по лог-линейной
модели с индивидуальной вариабельностью скорости снижения:

```
АМГ(t) = АМГ₀ × exp(−k × t)
```

Коэффициент k разыгрывается из логнормального распределения с параметрами,
откалиброванными по продольным когортным данным (Dölleman et al., Hum Reprod
2013; Tehrani et al., Fertil Steril 2011). Для каждой из 5 000 MC-траекторий
своё k — это формирует веер возможных биологических исходов, отражающий
реальную межиндивидуальную вариабельность скорости истощения овариального
резерва.

---

### Почему будущие циклы не описываются количественно по ОКК, MII и бластоцистам

Это принципиальное методологическое решение, а не ограничение реализации.

Прогноз ОКК, MII и эмбриологических показателей в основном pipeline строится
на конкретных параметрах конкретного цикла: дозах гонадотропинов, ответе
яичников на стимуляцию, качестве спермы в данный день, протоколе лаборатории.
Ни один из этих параметров неизвестен для гипотетических будущих циклов — они
будут определены в своё время, исходя из актуального состояния пациентки,
решений врача и условий протокола.

Выводить числа ОКК = 8, бластоцисты = 3 для «попытки №4 через два года» означало
бы подставлять популяционные медианы, никак не привязанные к этой пациентке,
и представлять их врачу в виде персонализированного прогноза. Это создаёт
ложную конкретность и клинически опасно: врач может опираться на эти числа
при принятии решений, хотя они несут не больше информации, чем общестатистические
таблицы по возрасту и АМГ.

TRP делает честное утверждение: **для будущих гипотетических циклов мы знаем
вероятностный горизонт, но не можем знать эмбриологические детали**. Это и
есть правильная граница инструмента — показывать то, что модель действительно
вычисляет, и не претендовать на то, чего она вычислить не может.

---

### Что TRP знает и говорит достоверно

**Кумулятивная вероятность беременности** нарастает с каждой попыткой.
Для каждого числа будущих циклов TRP даёт оценку P(≥1 беременность) с
доверительным интервалом P10–P90, полученным методом бутстрап по 5 000
траекторий. Это вероятностное утверждение, опирающееся на правильный
абсолютный уровень из KAT и правдоподобную модель его изменения во времени.

**Спад вероятности за цикл** отражает совместный эффект возрастного снижения
прогноза и эффекта отбора попыток. Разрыв между полной кривой (серые столбцы)
и референсной пунктирной линией (только биологический компонент) показывает,
насколько каждая дополнительная безуспешная попытка сама по себе снижает
прогноз независимо от биологии.

**Биологическое окно** (лет до АМГ < порогового значения или достижения
возрастного лимита) описывается распределением P10–P50–P90, отражающим
неопределённость в индивидуальной скорости снижения АМГ.

**Ответ на историю попыток**: если известны результаты предыдущих циклов
(фактическое ОКК), TRP вычисляет response ratio — отношение фактического ответа
к модельному ожиданию — и использует его для importance resampling MC-траекторий.
Пациентки с устойчиво сниженным ответом на стимуляцию получают траектории,
взвешенные в сторону менее благоприятных сценариев. Это patient-specific
кондиционирование, реализованное без переобучения нейросети.

---

### Границы применимости

TRP — инструмент стратегического консультирования, а не замена полноценному
прогнозу конкретного цикла. Перед каждой новой попыткой основной модуль Digital
Twin должен быть запущен заново с актуальными параметрами: текущим АМГ, АФЧ,
параметрами стимуляции и эмбриологическими данными по мере их появления.
Результаты TRP теряют актуальность при значимых изменениях клинического
статуса пациентки (операция на яичниках, смена протокола, существенное
изменение АМГ).
