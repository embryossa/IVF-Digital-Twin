# Файлы моделей

Актуальный список файлов моделей версии 7.1 и их назначение — в
[`README.md`](README.md) этой папки.

Прежнее содержание этого файла относилось к версии 6.x: файлы искались в трёх
местах, KAT калибровался обёрткой Venn-Abers (`KAT_calibrated_model.pkl`), а
слоем L5 была модель TabDDPM (`embryo_tabddpm_v3.pt`). В 7.1 слой L5 — CSDI
Hybrid v3 (`embryo_v3_model/`), а TabDDPM (`src/embryo_tabddpm.py`) сохранена
только как предыдущая, вытесненная версия.
