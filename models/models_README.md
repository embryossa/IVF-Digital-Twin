# Папка для файлов нейросетевых и диффузионных моделей

## L3 — Нейросетевой ансамбль (KAT)

Поместите сюда три файла:

| Файл | Описание |
|---|---|
| `Prediction_KAN.pth` | Веса KAN (PyTorch state dict) |
| `FTTransformer.joblib` | FT-Transformer классификатор |
| `KAT_calibrated_model.pkl` | Откалиброванный ансамбль (Venn-Abers) |

Система ищет файлы в трёх местах (в порядке приоритета):
1. `src/`  — рядом с основным кодом
2. корень репозитория — рядом с `app.py`
3. `models/`  — эта папка

Если файлы не найдены — приложение автоматически переключается
на ансамбль FORTUNE+KPI без нейросети.

## L5 — Diffusion верификационная модель (TabDDPM)

Поместите сюда файл:

| Файл | Описание |
|---|---|
| `embryo_tabddpm_v3.pt` | Обученная диффузионная модель + квантильные скейлеры |

Файл содержит:
- Веса обученного денойзера (FiLM-EmbryoDenoiser)
- Квантильные нормализаторы conditioning и trajectory переменных
- Конфигурацию модели (T, hidden, n_blocks, и др.)
- Историю обучения

### Как получить файл

**Вариант A — обучить на своих данных:**
```bash
# Подготовьте all_df_with_KPI.xlsx в корне проекта
python src/embryo_tabddpm.py
copy embryo_tabddpm_v3.pt models\
```

embryossa@gmail.com

### Что происходит без файла

Вкладка **🧬 Diffusion** в приложении показывает инструкцию по подключению.
Все остальные вкладки (L1–L4) работают в полном объёме.
