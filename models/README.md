# Папка файлов моделей · IVF Digital Twin 7.1

Все файлы моделей кладутся **только сюда**, в `models/`. Версия 7.1 больше не
ищет их в `src/` и в корне репозитория. Веса и статистики в репозиторий не
входят (`.gitignore`); их можно запросить для исследовательского сотрудничества:
embryossa@gmail.com.

Каждый файл можно положить открытым или зашифрованным (`<имя>.enc`) — загрузчик
`src/modelio.py` принимает оба варианта; для `.enc` нужен модуль лицензирования
коммерческой сборки.

## L3 — нейросетевой ансамбль KAT

| Файл | Описание |
|---|---|
| `Prediction_KAN.pth` | Веса KAN (width [18, 10, 1], сетка 5, порядок 3) |
| `FTTransformer.joblib` | FT-Transformer (mambular 0.2.2) |
| `KAT_ensemble_raw_weights.pth` | Веса объединения KAN и FT-Transformer |
| `isotonic_ensemble.pkl` | Изотонический калибратор; в 7.1 применяется с линейной интерполяцией между центрами ступеней |

Без `Prediction_KAN.pth` и `FTTransformer.joblib` KAT недоступна: вероятность
FORTUNE+KPI продолжает работать, но в L7 как свидетельство не входит.

## L5 — CSDI Hybrid v3

Папка `embryo_v3_model/`:

| Файл | Описание |
|---|---|
| `config.json` | Конфигурация и порог `best_threshold` (входит в репозиторий) |
| `training_history.json` | История обучения (входит в репозиторий) |
| `csdi_weights.pt` | Денойзер CSDI |
| `normalizer.pt` | QuantileNormalizer |
| `lgb_state.pt` | Классификатор LightGBM |
| `platt_calibrator.pt` | Калибровка Платта |
| `conformal.pt` | Конформные радиусы |

Методика: `embryo_v3_model/CSDI_Hybrid_v3_Technical_Description.md`.

## Статистики применимости (OOD)

| Файл | Описание | Без файла |
|---|---|---|
| `befe_ood_stats.npz` | Двойной OOD-детектор L7 (схема 3: клиника [возраст, КАФ], эмбриология [OCC и эмпирико-байесовские доли]); принимается и схема 1 из `fit_befe_ood.py` | OOD-контроль выключен |
| `csdi_ood_stats.npz` | Область применимости CSDI | CSDI показывается, но в L7 не входит |

Файл с вырожденным измерением (признак без разброса в когорте) отклоняется:
иначе детектор отмечал бы как OOD каждую пациентку.

## Что работает без файлов

L1 + L2 + L4 и BEFE на приоре L1 работают полностью; L3, L5 и L6 сообщают
«модель не загружена». Недоступный слой в L7 не входит и ничем не подменяется.
