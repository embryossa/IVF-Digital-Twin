# Совокупный репродуктивный потенциал (TRP)
## Методологическое описание для клинического персонала · версия 7.1

---

### Какой вопрос решает TRP

Основной модуль Digital Twin отвечает на вопрос текущего цикла: какова вероятность
клинической беременности *при данных параметрах пациентки и данном эмбриологическом
ответе*? Итог — объединённая оценка слоёв L1–L7 (BEFE) на один перенос и
согласованная с ней вероятность за цикл.

TRP отвечает на другой вопрос: **каков репродуктивный ресурс пары на временно́м
горизонте?** Сколько биологически осуществимых попыток остаётся до закрытия
окна возможностей? Как суммарная вероятность первой беременности нарастает от
цикла к циклу? Когда снижение овариального резерва или возрастной фактор начнут
ощутимо менять прогноз? Это стратегический инструмент для консультирования — не
замена основному прогнозу, а его продолжение во времени.

TRP оценивает время до **первой** клинической беременности. Моделирование
желаемого числа детей не реализовано.

---

### Архитектура расчёта: два слоя

#### Слой 1 — Якорь: вероятность цикла по всему стеку L1–L7

Вероятность для первого цикла плана — та же вероятность беременности за цикл,
которую показывает основной экран (`cycle_probability`). Она получена так:
итоговая вероятность BEFE на перенос переносится на весь цикл — вероятности
сценариев Monte Carlo сдвигаются одной константой на логит-шкале так, чтобы их
среднее по сценариям с переносом равнялось итогу L7, а затем учитываются все
доступные эмбрионы и сценарии без переноса. Введённые результаты текущего цикла
(ОКК, 2PN, бластоцисты) меняют якорь ровно так же, как меняют карточку результата.

**Если перенос в текущем цикле невозможен** (введён ноль ооцитов, MII, 2PN или
бластоцист, либо ноль эуплоидных при ПГТ-А), итог текущего цикла равен нулю, но
план будущих попыток не обнуляется: якорь пересчитывается для нового цикла той же
пациентки без наблюдений текущего. Источник якоря показывается:
`current-L1-L7` или `prospective-L1-L7` (`prospective-L1-L4`, если L7 недоступен).

До 7.1 якорем служила вероятность L1–L4 (`p_overall_cycle`) или «сырая»
вероятность KAT; это расходилось с числом на экране.

#### Слой 2 — Аналитическая экстраполяция (будущие циклы)

Для каждого последующего цикла s вероятность вычисляется по формуле:

```
logit(p_s) = logit(p_base)
           + [logit_FORTUNE(возраст_s, АМГ_s) − logit_FORTUNE(возраст_0, АМГ_0)]
           − 0.08 × s
```

`logit(p_base)` — якорь из слоя 1: персонализированная оценка, а не популяционная
медиана.

`Δlogit_FORTUNE` — относительное изменение прогноза по мере старения и снижения
АМГ. Используется та же модель FORTUNE, что и в слое L2 (Carrasquillo et al.,
Hum Reprod 2025), и только как мера *направления* изменений, а не как источник
абсолютных значений. Благодаря этому биологический дрейф учитывается без искажения
исходного уровня.

`0.08 × s` — эффект отбора попыток (Malizia et al., NEJM 2009). Пациентки,
которые продолжают лечение после неудачных циклов, в совокупности представляют
менее благоприятную прогностическую группу. Коэффициент 0.08 на логит-шкале
соответствует примерно 7–9% относительного снижения вероятности за каждую
дополнительную попытку.

Вероятности 0 и 1 сохраняются как есть; некорректный якорь (вне [0, 1]) отклоняется.

#### Моделирование снижения АМГ

АМГ экстраполируется по лог-линейной модели с индивидуальной скоростью снижения:

```
АМГ(t) = АМГ₀ × exp(−k × t)
ln k ~ N(ln 0.07, 0.45)
```

Параметры распределения k откалиброваны по продольным когортным данным (Dölleman
et al., Hum Reprod 2013; Tehrani et al., Fertil Steril 2011). Для каждой из
траекторий (по умолчанию 5 000) своё k — это формирует веер биологических
сценариев, отражающий межиндивидуальную вариабельность истощения резерва.

#### Закрытие окна

Цикл в траектории доступен, пока АМГ ≥ порога (по умолчанию 0.10 нг/мл),
возраст < лимита (по умолчанию 45 лет) и вероятность за цикл ≥ минимальной
(по умолчанию 3%). Число доступных циклов ограничено горизонтом плана (по
умолчанию 6 попыток, интервал 3 месяца).

#### Расчёт без розыгрыша исходов

В 7.1 исходы циклов не разыгрываются монетой, а интегрируются: для каждой
траектории вычисляется вероятность отсутствия успеха до цикла c как произведение
(1 − p) по доступным циклам, затем результат усредняется по траекториям.
Поэтому первый цикл кумулятивной кривой в точности равен якорю, а разброс
P10–P90 (бутстрап по траекториям) отражает только веер снижения АМГ, а не шум
Monte Carlo.

---

### Почему будущие циклы не описываются количественно по ОКК, MII и бластоцистам

Это принципиальное методологическое решение, а не ограничение реализации.

Прогноз ОКК, MII и эмбриологических показателей в основном pipeline строится
на параметрах конкретного цикла. Для гипотетических будущих циклов они
неизвестны — они будут определены в своё время, исходя из актуального состояния
пациентки, решений врача и условий протокола.

Выводить числа ОКК = 8, бластоцисты = 3 для «попытки №4 через два года» означало
бы подставлять популяционные медианы и представлять их врачу как
персонализированный прогноз. Это создаёт ложную конкретность и клинически опасно.

TRP делает честное утверждение: **для будущих гипотетических циклов мы знаем
вероятностный горизонт, но не можем знать эмбриологические детали**.

### Что TRP показывает

**Кумулятивная вероятность первой беременности** для каждого числа будущих
циклов, с интервалом P10–P90 по вееру АМГ.

**Вероятность за цикл по медианной траектории** — совместный эффект возрастного
снижения прогноза и эффекта отбора попыток. После закрытия окна она равна нулю.

**Биологическое окно** — лет до АМГ ниже порога или достижения возрастного лимита
(P10–P50–P90).

**Ожидаемое число циклов до успеха** — среднее по распределению номера первого
успешного цикла при условии успеха в пределах плана; **вероятность, что окно
закроется раньше успеха**.

**История попыток.** Прошлые циклы (возраст, ОКК, бластоцисты, исход) сохраняются
в плане и описываются отдельно, но в 7.1 **не меняют чисел TRP**. Прежнее
перевзвешивание траекторий по отношению фактического ответа к ожидаемому не было
связано ни со скоростью снижения АМГ, ни с вероятностью успеха и лишь
перевзвешивало шум Monte Carlo; оно отключено до появления совместной модели
ответа и прогноза.

---

### Границы применимости

TRP — инструмент стратегического консультирования, а не замена прогнозу
конкретного цикла. Перед каждой новой попыткой основной модуль Digital Twin
должен быть запущен заново с актуальными параметрами: текущим АМГ, АФЧ и
эмбриологическими данными по мере их появления. Результаты TRP теряют
актуальность при значимых изменениях клинического статуса пациентки (операция на
яичниках, смена протокола, существенное изменение АМГ).
